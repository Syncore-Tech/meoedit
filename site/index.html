Vì sao dùng meoedit

Miễn phí, mã nguồn mở
Giấy phép MIT. Không tài khoản, không đăng nhập, không trả tiền theo từng template.
Clip không rời khỏi máy
Mọi thứ dựng bằng ffmpeg ngay trên máy bạn. Không tải ảnh, video hay giọng nói lên đâu cả.
Tiếng Việt đủ dấu
Font Be Vietnam Pro, Baloo 2, Dancing Script hiển thị chuẩn từng dấu. Câu hỏi và chữ mẫu viết sẵn bằng tiếng Việt.
Duyệt trước, sửa tiếp trong CapCut
Agent gửi bản nháp và chờ bạn đồng ý mới xuất bản cuối. Muốn tự chỉnh thêm thì xuất thành project CapCut, giữ nguyên font, chữ và nhạc.
Agent nào cũng dùng được
Claude Code cài bằng một lệnh plugin, Codex bằng install.sh. Cursor, Gemini CLI hay agent khác chỉ cần đọc file SKILL.md.
Tự làm template được
Một template chỉ là một file style.json và một file hướng dẫn. Sửa màu, font, vị trí chữ trong vài phút.

Cài đặt

Cần Python 3.9 trở lên và ffmpeg. Trên Windows, cài ffmpeg bằng winget install ffmpeg; trên Ubuntu, dùng sudo apt install ffmpeg.

# macOS
$ brew install ffmpeg
$ python3 -m pip install --user pillow
# cài skill cho Claude Code
$ claude plugin install meoedit --marketplace Syncore-Tech/meoedit

Đang mở Claude Code thì gõ /plugin install meoedit --marketplace Syncore-Tech/meoedit. Codex, Cursor và agent khác: xem hướng dẫn trên GitHub.
